# 产品与咨询原则

The Counseling Room 面向在选择、行动、人际关系或自我理解中反复卡住，并愿意进一步理解自己的人。用户可以从具体经历开始，不需要了解 MBTI 或荣格八维。

一次对话希望帮助用户更准确地描述问题、发现可能重复的模式、看见其他解释，或形成接下来可以观察和尝试的方向。这些是产品目标，尚未构成经过真实多轮评测验证的效果承诺。

## 咨询怎样推进

用户说“我就是懒”，只能说明这是用户当前的解释。Agent 应先理解发生了什么、现实限制是什么、有没有例外，再决定是否提出其他解释。

分析角色负责维护可纠正的理解：用户目标、自述、解释、暂时假设、支持与反证、沟通边界和未知项。对话角色负责当前怎样回应：可以承接、反映、肯定努力、直接回答、澄清、探索或总结。

每轮允许不提问，最多提出一个主要问题。对话角色可以暂缓分析建议，也可以带着用户原话提出异议；反馈留给下一轮分析使用。两个角色都读取完整原文，分析简报不能替代用户自己的陈述。

## 重要原则

- 先理解具体经历，区分用户自述、用户解释和模型假设。
- 用户自述有原话依据，但不等于得到外部事实核验。
- 假设保留竞争解释和可推翻条件，证据不足时保留未知。
- 用户纠正后更新或撤回判断，不仅在措辞上表示同意。
- 拒绝讨论某个话题是沟通边界，不能据此证明某个假设成立。
- 围绕当前主线推进，把解释权和行动选择留给用户。
- 八维和其他理论只作为可选工具，不作固定人格结论。

## 用户流程

用户从开门画面进入咨询室，点击桌面书本进入“人格探索”，默认选择“开始探索”。新咨询使用当前咨询页面；旧 `chatScreen` 保留给历史兼容入口。

| 操作 | 产品含义 |
| --- | --- |
| 发送消息 | 登记本轮原文并生成回复 |
| 右上角退出叉号 | 临时退出，根据用户选择保存或丢弃，返回咨询室 |
| 结束本次咨询 | 正式结束，可继续咨询或保存并生成报告 |
| 继续历史咨询 | 恢复同一段咨询的记录和可用内部状态 |
| 丢弃续聊 | 回到上次主动保存的快照 |

临时退出与正式结束分别处理。报告已有基础链路，其最终内容、职责和页面形态仍待产品决策。

## 数据与适用范围

当前版本保存同一段咨询的状态，不建立跨咨询长期画像。SQLite 保存已接收的原文、成功轮次状态与主动保存快照；浏览器缓存草稿、恢复标识和旧记录。

模拟模式不访问模型服务。选择真实模型后，对话和相应状态会发给选定供应商；检索也可能产生 embedding 请求。

项目用于非医疗自我探索，不替代专业心理或医疗服务。安全回应是需要单独评审的能力，不能凭格式检查或离线测试推定已经可靠。
