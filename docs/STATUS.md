# 当前状态与待办

文档核对日期：2026年11月17日。当前实现仍为2026年10月27日的本地双角色版本。本次公开前完成Python 160、Node 193、Edge 7项检查及类型/构建验证，执行范围和限制见[发布验证](VALIDATION.md)。

## 已有本地实现

- Vite 与原生 JavaScript 咨询室前端，Python FastAPI 默认后端。
- LangGraph 固定分析、对话、程序检查流程，mock/千问/DeepSeek 共用同一双角色图。
- 角色分别配置；原话引用、稳定条目、撤回依赖、修订与沟通反馈。
- 统一模型/检索次数、180秒期限和160000字节供应商请求体预算。
- 本机 SQLite、原文先登记、完整结果原子保存、请求去重与版本检查。
- 保存与丢弃快照、断流查询、重启恢复和旧历史显式导入。
- 既有报告兼容链路，以及相应 Python、Node 和本机 mock 浏览器回归。

## 尚未完成的验证

当前双角色的真实多轮咨询质量尚未验收。工程记录不能回答是否听懂了用户、提问时机是否恰当、挑战是否有帮助，以及持续对话体验是否自然。

模型账户权限、当前外部服务可用性与费用应在真实试用前核实。其他操作系统的完整流程、公开多用户运行和 Python 云部署也没有由现有本机验收覆盖。

独立仓库的真实模式启动仍含原工作区目录层级假设：CLI 无条件读取 `ROOT.parents[3]`，浅层目录可能启动失败。mock 不受这段逻辑影响；这项可移植性问题尚未修改。
